# 风机偏航对中台

现场技师登记机组编号与偏航误差（度）；服务端下结论前先扣齿轮箱温漂：按机组温漂系数与机舱温度算出补偿后偏航，再按 ±1.5° 阈值写入「合格」或「偏航超差」。原始读数与补偿后读数同笔记入补偿账。前端为 Lit 组件 + Vite，接口为 Quart + Hypercorn。

## 温漂补偿规则

- 补偿后偏航 = 原始读数 + 温漂系数 ×（机舱温度 − 基准温度）。
- 例：系数 0.1 度/℃、机舱温度较基准抬高 10℃，补偿后较原始读数偏大 1°；仍落 ±1.5° 内判「合格」，人为抬至超限判「偏航超差」。
- 边界：温漂系数 0~1.0 度/℃，基准温度 -30~50 ℃，机舱温度 -40~80 ℃。缺机舱温度或系数越界时报送一律退回，并返回明确说法。
- 报送即入队，入队（`yaw_logs`）与补偿账落笔（`compensation_ledger`）在同一事务提交，任一侧失败整题作废。
- 补偿账落笔后不回写：事后改在线单据展示数字（`PUT /api/logs/{id}`），账里当时写下的旧值保持原样，可在专页流水区单独回看。

## 页面

顶栏两个入口：

- **对中记录**：记录表（展示误差、机舱温度、补偿后读数、状态、结论）；技师可「改数」修正单据展示数字。
- **齿轮箱温漂补偿账**（专页三区）：
  - 系数区：机组温漂系数与基准温度的查看与设置（仅技师可改）；
  - 报送栏：技师报送机组编号、原始偏航误差、机舱温度；
  - 流水区：补偿账逐笔流水（原始读数、机舱温度、系数、基准温度、补偿后读数、记录人、记录时间）。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/auth/login` | 登录取 token |
| GET | `/api/logs` | 记录列表（登录即可） |
| POST | `/api/logs` | 报送（技师）：校验温度与系数后同事务入队+落账 |
| PUT | `/api/logs/{id}` | 改单据展示误差（技师），不动补偿账 |
| GET | `/api/coefficients` | 系数列表（登录即可） |
| PUT | `/api/coefficients/{turbine}` | 设/改机组系数（技师），越界退回 |
| GET | `/api/compensation-ledger` | 补偿账流水（登录即可） |

## 验收

1. 种子数据：机组 W01 误差 0.4° 结论「合格」；机组 W07 误差 3.2° 结论「偏航超差」；两机组系数均为 0.1 度/℃、基准 20℃。
2. technician 在系数区为机组设系数（如 0.1 度/℃、基准 20℃），在报送栏报送误差 0.5°、机舱温度 30℃ → 补偿后 1.5°，数秒内 worker 判「合格」；报送误差 1.0°、机舱温度 30℃ → 补偿后 2.0°，判「偏航超差」。
3. 报送缺机舱温度 → 退回并提示「缺机舱温度」；设系数 2.0 → 退回并提示「温漂系数越界」。
4. 每笔报送在流水区有一笔账；用「改数」改单据展示误差后，流水区仍是当时旧值。
5. observer 可查看记录表、系数与补偿账，无报送表单、不能改系数（接口返回 403）。
