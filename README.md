# 风机偏航对中台

现场技师登记机组编号、偏航误差（度）与机舱温度（℃）。服务端下偏航结论前先扣齿轮箱温漂：

```
补偿后偏航 = 原始偏航 + 温漂系数 × (机舱温度 − 基准温度)
```

后台 worker 用数据库行锁认领待处理记录，对**补偿后偏航**按 ±1.5° 阈值写入「合格」或「偏航超差」。入队与补偿账落笔在同一事务内捆绑提交。

## 顶栏分区

登录后顶栏切换两页：

- **对中记录（在线单据）**：展示原始读数、机舱温度、补偿量、补偿后读数与结论；「展示读数」允许技师事后修改，仅影响本单显示。
- **齿轮箱温漂补偿账（专页）**，分三区：
  - **报送栏**：技师按机组报送原始读数 + 机舱温度；
  - **系数区**：技师为机组设置温漂系数与基准温度；观察员可看不可改；
  - **流水区**：每笔落笔时的原始读数、机舱温度、所用系数/基准温度、温差、补偿量、补偿后读数与结论的**快照账**，事后在线单据展示数字被改动，流水旧值保持不变、可逐笔单独回看。

## 校验与退回

- 报送缺机舱温度：`400 报送须填写机舱温度，否则无法进行齿轮箱温漂补偿`
- 机舱温度越界（−50℃～100℃）：`400` 并说明范围；
- 温漂系数越界（−1.0～1.0 度/℃）或基准温度越界：保存即 `400` 并说明范围；
- 机组尚未设置系数即报送：`400` 提示先到系数区设置。

## 原子性

报送接口在**单个数据库事务**内：取系数 → 算补偿 → 插入对中记录（pending）→ 写补偿账。任一步失败整笔回滚，队列与补偿账不会只成一侧（两侧未齐整，题作废）。

## 验收

1. 种子：W01 原始 0.4°（机舱 20℃，系数 0.1，基准 20℃，补偿量 0）→ 合格；W07 原始 3.2° → 偏航超差。
2. 系数设 **0.1 度/℃、基准 20℃**，报送 W12 原始 0.4°、机舱 **30℃**（抬高 10℃）：补偿量 +1.0°，补偿后 **1.4°**，较原始偏大 1°，仍在 ±1.5° 内 → **合格**。
3. 同一机组机舱抬到 **35℃**：补偿后 0.4+1.5=**1.9°** → **偏航超差**。
4. 报送不带机舱温度、或温度/系数越界 → 提交被退回且错误信息说明原因。
5. observer 登录：能看对中记录与补偿账三区数据，看不到报送/系数表单，接口直调写操作返回 403。
6. 在对中记录页把某单「展示读数」改为任意值：在线显示变化，但补偿账流水里当时落笔的原始/补偿后旧值不变。
7. 提交后列表先「待处理」，数秒内 worker 处理后变为结论，流水区结论同步回填。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | - | 登录取 token |
| GET | `/api/logs` | 登录 | 对中记录列表 |
| POST | `/api/logs` | 技师 | 报送（须带 `nacelle_temp_c`），入队+落账 |
| PATCH | `/api/logs/{id}` | 技师 | 仅改在线展示数字 `display_yaw_deg` |
| GET | `/api/coeffs` | 登录 | 系数列表 |
| PUT | `/api/coeffs/{turbine}` | 技师 | 设置/更新系数与基准温度 |
| GET | `/api/ledger` | 登录 | 补偿账流水（快照） |
